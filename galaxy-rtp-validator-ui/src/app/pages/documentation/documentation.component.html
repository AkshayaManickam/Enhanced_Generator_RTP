Galaxy RTP Documentation

Comprehensive documentation for the Galaxy RTP Generator & Validator. Learn about API endpoints, message formats, and integration guidelines.

Overview

The Galaxy RTP Generator & Validator is a comprehensive tool for working with ISO 20022 RTP (Real-Time Payments) messages. It provides both message generation and validation capabilities to ensure compliance with financial messaging standards.

Message Generation

Generate ISO 20022 compliant RTP messages with realistic test data for various scenarios including customer credit transfers and payment returns.

Message Validation

Validate RTP messages against ISO 20022 schemas and business rules to ensure compliance and identify potential issues.

Key Features

  • Support for PACS.008 (Customer Credit Transfer) message type
  • Real-time message generation with configurable parameters
  • Comprehensive validation against ISO 20022 schemas and business rules
  • RESTful API for seamless integration with existing systems
  • Detailed error reporting and validation results

API Reference

The Galaxy RTP API provides RESTful endpoints for message generation and validation. All endpoints return JSON responses and support standard HTTP status codes.

POST /rtp-message/rtp/messages

Generate RTP Messages

Generate multiple RTP messages based on specified parameters.

Request Parameters:

  • • numberOfFiles: Number of messages to generate
  • • messageType: Type of message (pacs.008)

Response:

Array of XML strings containing the generated messages

POST /rtp-message/rtp/validate

Validate RTP Message

Validate an RTP message against schemas and business rules.

Request Parameters:

  • • xmlContent: XML content to validate
  • • messageType: Type of message (optional)

Response:

Validation results with success status and error details

GET /rtp-message/actuator/health

Health Check

Check the health status of the RTP service.

Message Types

The Galaxy RTP system supports the following ISO 20022 message types for real-time payments.

PACS.008 - Customer Credit Transfer

The PACS.008 message is used for customer credit transfers in real-time payment systems. It contains information about the transfer of funds from one account to another.

Key Elements:

  • • Group Header (GrpHdr) - Contains message identification and settlement information
  • • Credit Transfer Transaction Information (CdtTrfTxInf) - Contains individual transfer details
  • • Instructing Agent (InstgAgt) - The financial institution initiating the transfer
  • • Instructed Agent (InstdAgt) - The financial institution receiving the transfer
  • • Creditor (Cdtr) - The beneficiary of the transfer
  • • Debtor (Dbtr) - The originator of the transfer

Integration Guide

Learn how to integrate the Galaxy RTP Generator & Validator into your existing systems and workflows.

Getting Started

1. Prerequisites

  • • Backend service running on port 8080
  • • Frontend application accessible via web browser
  • • Network connectivity between your system and the RTP service

2. API Authentication

Currently, the API does not require authentication. Ensure your requests include proper headers:

Content-Type: application/json

Accept: application/json

Best Practices

Error Handling

  • • Always check HTTP status codes in your responses
  • • Handle network errors and timeouts gracefully
  • • Implement retry logic for transient failures
  • • Log validation errors for debugging purposes

Performance

  • • Limit the number of files generated per request (max 100)
  • • Use appropriate timeout values for API calls
  • • Consider implementing caching for frequently used validations
  • • Monitor API response times and adjust accordingly
